# PBI: FTS 再構築条件を全空のみから件数比較に緩和

## ユーザーストーリー
利用者として、再構築の中断後も検索インデックスが自動修復されてほしい、なぜなら検索結果が恒久的に不完全になるのを防ぎたいから

## 優先度
- 順位: 06 / 26
- RICEスコア: 3200（Reach=1000 / Impact=1 / Confidence=0.8 / Effort=0.25日）
- 根拠: 検索インデックスの不完全化はデータ品質問題。修正が小さく（条件式1行）影響が大きいため高優先度

## BDD受け入れシナリオ
```gherkin
Scenario: 部分投入されたFTSインデックスが修復される
  Given 本体テーブルに100件のログがありFTSテーブルに50件のみ投入されている
  When  マイグレーションが実行される
  Then  FTSインデックスが再構築され全100件が検索対象になる

Scenario: 正常なFTSインデックスでは再構築されない
  Given 本体テーブルとFTSテーブルの件数が一致している
  When  マイグレーションが実行される
  Then  再構築は実行されず起動が高速に完了する

Scenario: 空データベースでは再構築されない
  Given 本体テーブルが空である
  When  マイグレーションが実行される
  Then  再構築は実行されない
```

## 受け入れ基準
- [ ] `ftsCount < baseCount` の場合に再構築が実行される
- [ ] `ftsCount >= baseCount` の場合に再構築が実行されない
- [ ] `baseCount = 0` の場合に再構築が実行されない
- [ ] 再構築チェック失敗時もマイグレーション全体が継続する（警告ログのみ）

## テスト戦略
- 単体: 件数組み合わせ（一致・不足・全空・空DB）ごとの再構築実行有無を検証する

## 実装アプローチ
再構築条件を全空判定から件数比較に緩和する
