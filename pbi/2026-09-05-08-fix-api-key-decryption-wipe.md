# PBI: 復号失敗時の API キー空文字上書きを防止

## ユーザーストーリー
利用者として、復号に失敗したAPIキーが空文字で上書きされず元のまま保全されてほしい、なぜなら再認証で復旧できるはずの鍵が永続化で失われると復元不能になり、暗号化保管という前提が崩れるから
