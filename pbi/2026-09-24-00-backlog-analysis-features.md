## 採点表（全13採用候補・共通尺度）

RICE = (Reach × Impact × Confidence) / Effort。Reach は月間アクティブユーザーのうち四半期内に当該機能へ触れる層の相対指数（10 = 最大）。Impact は 3=圧倒的 / 2=大きい / 1.5=中上 / 1=中 / 0.5=小。Confidence は 100% / 80% / 50%。Effort は SP。

実行順 = 着手順 NN: 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08

## 主要設計決定（なぜなぜ分析による自律解決）

- **スライダーの「変化の見せ方」**: side-by-side（2 SVG）＋ diff 一覧（出現/消失/増減タグ）。アニメーション遷移はユーザー確定でスコープ外
- **ワードクラスタの出力形式**: クラスタグラフ（タグクラスタと同一 UI）= tag-cooccur パイプラインを words-as-tags アダプタで再利用。テキスト源は summary（AI 応答）+ title。content はデフォルト設定 OFF で大半が null のため対象外
- **ワードクラスタの日本語抽出**: Intl.Segmenter（granularity:'word'）+ ストップワード/最小長フィルタ。形態素解析器は辞書サイズと CSP 対応が重いため不採用。品質未検証（Confidence 50%）は STEP 0 の実データプローブで軽減
- **ワードクラスタのデータ品質処理**: 'Summary not available.' フォールバック文字列と AI 失敗行（summary null）は集計から除外し、除外件数を表示
- **ドメイン分析の粒度**: hostname のまま集計（storage 実態と一致。eTLD+1 ロールアップは将来拡張）。ドメイン集計と URL top N を両方提供。クライアント側集計で wire op 追加不要
- **期間指定タグクラスタの後方互換**: デフォルト「全期間」＝現行挙動と同一。クリック遷移は期間を引き継がない（v1）
- **ヒートマップのタイムゾーン**: ローカル時刻で集計（created_at は epoch ms）
