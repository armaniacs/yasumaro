## 重要指摘事項（優先度順）

### [High] ライブリージョンが200msごとに再アナウンスされ、スクリーンリーダーが洪水状態になる
- 指摘者: Accessibility Advocate、Ethics & Bias Auditor、UI Expert、Tuning Expert
- 場所: `src/dashboard/dashboard.ts`（`renderAiTestProgress` の `setInterval(200)` + `innerHTML=''` 全置換）
- 影響: `#status` / `#statusTop` は両方 `aria-live="polite"`。200ms ごとに全体を再構築し 2 リージョンへ複製するため、経過秒が変わるたびに読み上げが二重で洪水する。加えてスピナーの CSS アニメーションも毎 tick リセットされ滑らかに回らない。
- 対処: **対応済み** — DOM を 1 度だけ構築し、経過時間は `textContent` のみ更新（`aria-hidden`）。プロバイダー切替時のみラベル（ライブリージョン）と `syncStatusToTop()` を更新。

### [Medium] 🎯 AI_TEST_PROGRESS 受信側が sender / payload 検証を欠く（一方向 broadcast の spoof 可能）
- 指摘者: Red Team、Blue Team
- 場所: `src/dashboard/dashboard.ts`（`progressListener` / `isAiTestProgressMessage`）
- 影響: `chrome.runtime.sendMessage` は全拡張コンテキストに届く。`type` 一致のみで sender を見ないため、乗っ取られた content script から進捗表示を偽装できる（`textContent` 描画のため DOM XSS にはならない）。
- 対処: **対応済み** — `if (sender?.id !== chrome.runtime.id) return;` を追加し、payload 形状は `isAiTestProgressMessage` で検証。偽 sender を無視するテストを追加。

### [Medium] 🎯 SW→全タブブロードキャストが content script の `return true` に巻き込まれ、ポート保持・未解決Promiseが増幅する
- 指摘者: Legacy Bridge、Domain Logic、API & Contract、SRE/Ops
- 場所: `src/content/extractor.ts:764`、`src/background/aiTestProgressNotifier.ts:31`
- 影響: `AI_TEST_PROGRESS` が開いている全タブの content script に届き、GET_CONTENT 以外でも `return true` でポートを保持。SW 側の sendMessage Promise がハングし、受信側タブのコンソールノイズも発生。
- 対処: **対応済み** — extractor.ts のリスナーを `if (msg.type !== 'GET_CONTENT') return;` に変更し、末尾の無条件 `return true` を削除。テスト追加。

### [Medium] モデル設定キー解決ロジックが3箇所に重複（ドリフトリスク）
- 指摘者: System Architect、Maintainability、Refactoring、Legacy Bridge
- 場所: `src/background/aiClient.ts`（`applySlotModel` / `resolveEffectiveModel`）、`src/background/ai/providers/OpenAIProvider.ts:51`
- 影響: `replace('2','_2').replace(/-/g,'_')` と `openai-compatible → PROVIDER_MODEL` の対応が重複。将来片方だけ修正すると「保存モデルと表示モデル」が黙って乖離する。
- 対処: **対応済み（aiClient.ts 内）** — `resolveModelKey(provider)` を抽出し両メソッドから参照。`OpenAIProvider.ts` 側は実リクエスト用の別責務のため今回スコープ外（後続リファクタ対象）。

### [Medium] `testConnection()` レスポンスの `model` フィールド値意味論が変化（`''` vs `undefined`）
- 指摘者: Legacy Bridge
- 場所: `src/background/aiClient.ts:275`
- 影響: 未指定スロットでデフォルト値が空文字 `''` の `provider_model` 経由だと `model: ''` が返り得る。`model === undefined` 判定の将来呼び出し元を壊す可能性。
- 対処: **対応済み** — `resolveEffectiveModel` で `''` を `undefined` に正規化。

### [Medium] 上部ボタン（testAiBtnTop）からテスト中に再実行でリスナー/タイマー/リクエストが二重化する
- 指摘者: System Architect、Legacy Bridge、Domain Logic、Test Experts、Red Team
- 場所: `src/dashboard/dashboard.ts`（`handleTestAi`）、`generalSettingsPanel.ts:128`
- 影響: `testAiBtn.disabled` は下部のみ。上部ボタンはテスト中も押せ、2 本目の listener + `setInterval` + `TEST_AI` が並走する。
- 対処: **対応済み** — モジュール変数 `aiTestInFlight` で再入ガード、上部ボタンも `disabled`。リスナー/タイマー生成を `try` 内へ移動し `finally` で確実にクリーンアップ（Red Team [Low] の例外安全性も解消）。

### [Medium] 🎯 prefers-reduced-motion 対応がデッドコード（グローバルルールに上書きされる）
- 指摘者: Accessibility、Edge & Mobile
- 場所: `entrypoints/options/dashboard.css`
- 影響: ローカルの `animation-duration: 2.4s` は tokens.css の `* { animation-duration: 0.01ms !important }` に上書きされ無効。しかも意図（遅くする）が既存方針（実質停止）と矛盾。
- 対処: **対応済み** — ローカルルールを削除し、グローバル方針に委ねる旨をコメントで明記。

### [Medium] 🎯 i18n フォールバックの言語が混在（英語 vs 日本語）
- 指摘者: i18n Expert
- 場所: `src/dashboard/dashboard.ts`（フォールバック文字列）
- 影響: 新規フォールバックは英語、既存の `接続テスト中...` は日本語。フォールバック発動時に言語が混ざる。
- 対処: **対応済み** — 主言語（日本語）に統一。

### [Medium] 🎯 AI_TEST_PROGRESS が VALID_MESSAGE_TYPES の一元管理の外にあり、契約として監視が抜ける
- 指摘者: API & Contract Negotiator

- 影響: 一方向 broadcast として意図的に外した設計判断は妥当だが、型の単一ソースから分散し将来ドリフトする。既存のメッセージ検証テストの対象外になる。
- 対処: 未対応（設計判断として許容）。`aiTestProgressNotifier.ts` 冒頭コメントで理由を明文化済み。将来は `messageTypes.ts` にアウトオブバンド型として列挙しテストを追加。

### [Medium] 🎯 リリースバージョンポリシーと矛盾（偶数バージョンで新機能追加）
