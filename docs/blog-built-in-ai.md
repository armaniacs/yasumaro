# ブラウザ組み込みAIだけで、APIキーなしで阅覧記録をAI要約する

## ポイント

最近のChromeやEdgeにはブラウザ組み込みのAIが載っています。APIキーを用意する必要はありません。ただし、遅いです。M1 Macだと一回の要約に30秒ほどかかります。しかし、バックグラウンドで動くので、普段は気になりません。

---

## APIキーがなくてもAI要約が動く

Yasumaro（旧 Obsidian Weave）でAI要約を使うには、従来は Groq や Gemini、OpenAI などのクラウドAPIキーが必要でした。

しかし、最近のChrome（Gemini Nano）とEdge（Phi-mini）では、ブラウザにAIモデルが内蔵されています。外部へのAPI呼び出しなしで、デバイス上で直接AI要約が可能です。

Yasumaro はこの組み込みAIに対応しています。設定画面で「Built-in AI」を選べば、APIキーは不要です。

```
Yasumaro ダッシュボード > AI 設定
  プロバイダー: Built-in AI (Gemini Nano / Phi-mini)
```

## 遅い。でも気にならない

率直に言って、組み込みAIは遅いです。

筆者の環境（M1 MacBook Pro、16GB）では、1ページの要約生成に概ね30秒ほどかかります。クラウドAPIとの比較はこんな感じです。

| プロバイダー | 1ページの要約時間 | インターネット |
|---|---|---|
| Built-in AI（Gemini Nano） | 25〜30秒 | 不要 |
| Groq | 1〜2秒 | 必要 |
| Gemini API | 2〜3秒 | 必要 |

30秒は長い。しかし、要約はバックグラウンドで実行されます。浏览中に自動トリガーされ、結果は拡張機能が保存するだけ。ユーザーが待つ必要はありません。

実際、筆者は組み込みAIを2週間ほど使っていますが、要約が完了したタイミングを意識したことは一度もありません。

## なぜ遅いのか

ブラウザ組み込みAIは、GPU を使わずにCPUだけで推論を実行します。Chrome の Gemini Nano モデルは約30億パラメータの軽量モデルですが、CPU推論は性質上遅いです。

Edge の Phi-mini も同様で、コンテキストウィンドウ（一度に処理できるテキスト量）が9,216トークンと狭いです。長いページは途中で切り詰められます。

速度を気にするならクラウドAPIを使えばいい。組み込みAIの利点は別にあります。

## 組み込みAIの本当のメリット

組み込みAIは「遅い」と「無料」だけではありません。3つの重要な特性があります。

1. **データがデバイスを離れない** — 閲覧ページの内容はAIの推論結果も含め、外部に送信されません。プライバシーを最優先する人にはこれが決定的です。

2. **コストゼロ** — API実行回数の制限もトークン課金もありません。日数百件のページを記録する人でも、コスト心配はゼロです。

3. **オフラインで動く** — ネット接続がなくてもAI要約は生成されます。移動中やネットワークの悪い環境でも記録を続けられます。

## セットアップ方法

Chrome の場合：

1. アドレスバーに `chrome://flags/#prompt-api-for-gemini-nano` を入力
2. **Enabled** または **Enabled multilingual** を選択
3. Chrome を再起動
4. 初回起動時にモデルが自動ダウンロードされる（22GBの空き容量が必要）

Edge の場合：

1. アドレスバーに `edge://flags/#edge-llm-prompt-api-for-phi-mini` を入力
2. **Enabled** を選択
3. Edge を再起動

詳細は [組み込みAI設定ガイド](BUILT_IN_AI_SETUP_GUIDE.md) を参照してください。

## どんな場面で組み込みAIが向いているか

- プライバシーを最優先したい
- APIコストをかけたくない
- 閲覧記録の要約を「完全にゼロから」作りたい
- ネット環境が不安定

逆に、クラウドAPIが向いているのは：

- 速度を重視する
- 高品質な要約が欲しい
- 多言語の長文を扱う

両方併用も可能です。Yasumaro はプロバイダーを1〜3位まで設定でき、1位が失敗した場合は自動的に2位、3位へフォールバックします。組み込みAIをメインに、フォールバックでクラウドAPIという構成がおすすめです。

## 組み込みAIは今後どうなるか

Chrome 131 以降で Gemini Nano がデフォルト有効になり、2025年後半にはフラグ不要になる見込みです。Edge の Phi-mini も同様に、ブラウザ標準機能として整備が進んでいます。

速度も年々改善されています。将来的にはGPU推論のサポートも拡大され、30秒→5秒程度に短縮される可能性があります。

APIキーなし、データ外部送信なし、コストゼロ。浏览記録のAI要約を試す入口として、組み込みAIは十分な選択肢です。
