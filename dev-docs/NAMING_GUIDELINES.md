# Naming Guidelines

> Source of truth for product naming across code, documents, UI, and release notes. Referenced from [AGENTS.md](../AGENTS.md).

## Official Notation

| Usage | Notation |
|-------|----------|
| Repository & package name | `yasumaro` |
| Extension name, UI, document headings | `Yasumaro` / `Yasumaro - AI Browsing Logger` |
| GitHub link text | `yasumaro` |

## Prohibited Names (Deprecated)

- `obsidian-weave` — old name. Do not use in new documents.
- `obsidian-smart-history` — old repository name. Do not use in new documents.
- `Obsidian Weave` — old extension name. Do not use in new documents.
- `Obsidian Smart History` — old extension name. Do not use in new documents.

## Blog & Release Notes Checklist

- GitHub link: `[yasumaro](https://github.com/armaniacs/yasumaro)`
- Headings & body: `Yasumaro v1.x` format
