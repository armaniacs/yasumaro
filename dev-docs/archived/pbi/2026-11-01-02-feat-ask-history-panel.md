# PBI: 履歴に聞くの独立パネル新設

## ユーザーストーリー

ダッシュボード利用者として、履歴への質問と対象コレクションの選択を履歴と独立した専用パネルで使いたい。質問機能を探す場所を明確にし、履歴の閲覧と混ざらないようにしたいから。

## 優先度

- 順位: 2 / 4
- RICEスコア: 0.64（Reach=0.3 / Impact=2 / Confidence=80% / Effort=0.75人週）
- 根拠: PBI 01 と同点のため、基盤側（コレクション管理）を先行させるタイブレークで次点。履歴への依存を持たない。

## BDD受け入れシナリオ

Scenario: コレクションを対象に質問する
  Given 保存済みコレクションが存在する
  When 新パネルで対象を選び質問を入力して聞く
  Then 端末内のモデルが記録の抜粋を根拠に答え、根拠のリンクから元の記録に移動できる

Scenario: 証拠がない場合は分からないと表示する
  Given 条件に合う記録がない
  When 新パネルで質問する
  Then 「分かりません」と表示され、ファイルや履歴は作られない

Scenario: 失敗時は理由が表示され再試行できる
  Given 生成に失敗する
  When 新パネルで質問する
  Then 失敗の理由が表示され、もう一度聞くことで再試行できる
