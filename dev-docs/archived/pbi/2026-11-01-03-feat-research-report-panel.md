# PBI: 調査レポート一発生成の独立パネル新設

## ユーザーストーリー

ダッシュボード利用者として、調査レポートの生成を履歴と独立した専用パネルで使いたい。対象の決め方を保存済みコレクションに寄せ、履歴の検索条件に縛られないようにしたいから。

## 優先度

- 順位: 3 / 4
- RICEスコア: 0.42（Reach=0.3 / Impact=1.5 / Confidence=70% / Effort=0.75人週）
- 根拠: 対象解決（コレクションから条件への変換）が3件中で最も新規性が高く、確信度を下げた。履歴への依存を持たない。

## BDD受け入れシナリオ

Scenario: コレクションを対象にレポートを生成する
  Given 条件に合う記録がある保存済みコレクションを選んだ
  When 新パネルでレポートを生成する
  Then 要旨・時系列・引用・未読穴の4節からなる Markdown が生成される

Scenario: 対象がない場合は理由が表示される
  Given 条件に合う記録がない
  When 新パネルでレポートを生成する
  Then 理由が表示され、ファイルは作られない

Scenario: Obsidian 送付の成否が分かる
  Given 対象コレクションを選んだ
  When Obsidian 送付を選んで生成する
  Then 成功時は書き出され、失敗時は理由が表示される

## テスト戦略

- E2E: 新パネルでの生成から Markdown 受け取りまでの通し（実機・外部連携が必要な分は owner 手動に委ねる）
- 統合: catalog と sidebar・分類の同期テスト更新、対象解決と生成の結合
- 単体: リージョン描画テストの移設と境界値（対象なし・送付失敗）
