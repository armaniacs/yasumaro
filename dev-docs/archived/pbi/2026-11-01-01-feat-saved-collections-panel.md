# PBI: 保存済みコレクションの独立パネル新設

## ユーザーストーリー

ダッシュボード利用者として、保存済みコレクションと自動タグ規則を履歴と独立した専用パネルで管理したい。履歴パネルは記録の閲覧に集中させ、保存条件の管理場所を明確にしたいから。

## 優先度

- 順位: 1 / 4
- RICEスコア: 0.64（Reach=0.4 / Impact=2 / Confidence=80% / Effort=1.0人週）
- 根拠: 分離全体の基盤。PBI 02・03 が対象として参照するコレクション管理の置き場所を先に確定させる。

## BDD受け入れシナリオ

Scenario: 新パネルでコレクションを呼び出す
  Given 保存済みコレクションが存在する
  When sidebar の新パネルを開く
  Then 一覧にコレクションが表示され、呼び出しで条件が復元される

Scenario: 空状態と規則の管理
  Given コレクションも規則もない
  When 新パネルを開く
  Then 空状態が表示され、規則の追加・無効化・削除ができる

Scenario: 読込失敗はパネル内で完結する
  Given 保存データの読込に失敗する
  When 新パネルを開く
  Then 理由がパネル内に表示され、履歴パネル側に影響しない
