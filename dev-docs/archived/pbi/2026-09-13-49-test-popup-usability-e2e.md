## BDD受け入れシナリオ

```gherkin
Scenario: ユーザーが記録開始からプレビュー確認、確定までを一連のタスクとして完了する
  Given ポップアップを開いており、記録可能なページがアクティブになっている
  When ユーザーが「Record Now」ボタンをクリックする
  Then プレビュー確認ダイアログが表示される
  When ユーザーが内容を確認し「確定」ボタンをクリックする
  Then ダイアログが閉じ、記録完了の状態表示に遷移する

Scenario: ユーザーが記録を中断してももとの状態に戻れる
  Given プレビュー確認ダイアログが表示されている
  When ユーザーがEscapeキーまたはキャンセル操作を行う
  Then ダイアログが閉じ、記録ボタンが押す前の状態（idle）に戻る
  And 記録データは送信されない

Scenario: 初見ユーザーがオンボーディングウィザードを最後まで迷わず完了する
  Given 拡張機能を初めてインストールしたユーザーの状態（初回起動）
  When onboardingWizard の各ステップを順に進める
  Then 各ステップで必須入力項目が明示されている
  And ウィザードを完了すると通常のポップアップ画面に遷移する

Scenario: 初見ユーザーがオンボーディング途中で離脱しても状態が壊れない
  Given onboardingWizard の途中のステップまで進んでいる
  When ユーザーが「閉じる」または「戻る」操作を行う
  Then 拡張機能の状態（設定・記録可否）は初期状態のまま矛盾なく保たれる
```
