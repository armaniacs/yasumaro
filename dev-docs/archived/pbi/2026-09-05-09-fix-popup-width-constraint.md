# PBI: popup 幅固定 360px を緩和し翻訳文字列クリップを解消

## ユーザーストーリー
多言語で拡張機能を使う利用者として、ポップアップ内のラベルやボタン文言が切れずに読めるようになってほしい、なぜなら独語・日本語など翻訳で長文化した文言が見切れると操作に必要な情報が欠落するから
