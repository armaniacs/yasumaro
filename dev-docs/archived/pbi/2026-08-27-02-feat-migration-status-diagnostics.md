# PBI: 診断パネルへの旧DB移行状態表示

## ユーザーストーリー

ユーザーとして、自分の環境で旧DB（wa-sqlite製 AccessHandlePoolVFS / IDBBatchAtomicVFS）からの
移行が完了しているかを診断パネルで確認したい、なぜなら移行が終わっているかどうかが分からないと
不安であり、開発側も外部送信のテレメトリなしに移行状況の実態を把握する手段がないから。

## 優先度

- 順位: 02 / 4
- RICEスコア: 25.0（Reach=5 / Impact=1 / Confidence=100% / Effort=0.2）
- 根拠: 移行完了フラグ（`opfs_migration_v2_done`, `idb_migration_v2_done`）は既に
  `chrome.storage.local` にローカル保存済み（`src/utils/storage/types.ts:233,238`）。
  既存の診断パネル（`src/dashboard/panels/diagnostic/diagnosticsPanel.ts`）に表示項目を
  1つ追加するだけで実現でき、外部送信を一切伴わないためプライバシー方針（全処理ローカル）と
  完全に整合する。他候補（03: 移行終息判断）の判断材料にもなるため、依存関係上も先行させる。

## BDDシナリオ

Scenario: 移行が完了している場合の表示
  Given `opfs_migration_v2_done` と `idb_migration_v2_done` が両方 true である
  When  診断パネルを開く
  Then  「旧データベースからの移行: 完了」という趣旨の表示がされる

Scenario: 移行が未完了の場合の表示
  Given いずれかのフラグが false である
  When  診断パネルを開く
  Then  「旧データベースからの移行: 未完了（該当データがない場合を含む）」という趣旨の表示がされ、
        ユーザーが不安にならないよう「新規インストールでは対象データがないため表示されます」等の補足がある
