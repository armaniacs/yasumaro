# PBI: チェックボックス運用ルールの逸脱（PBI 11・12）を是正する

## ユーザーストーリー
PBI 運用者として、完了 PBI が正しくアーカイブされてほしい、なぜなら「対応済みを確認して閉じた」PBI が pbi/ に未完了扱いで残ると、次回の自律クローサーやレビュアーが誤検出するから

## 優先度
- 順位: 06 / 7
- RICEスコア: 10（Reach=5 / Impact=1 / Confidence=80% / Effort=0.4）
- 根拠: 運用是正。pbi/ は「未完了のみ置く」規約のため、対応済み PBI 11・12 は規約違反状態にある

## ビジネス価値
未完了スキャンの信頼性が回復する。偽陽性の削減

## BDD受け入れシナリオ

```gherkin
Scenario: 対応済み PBI はアーカイブされる
  Given PBI 11 と 12 の受け入れ基準がすべて [x] である
  When 運用ルールに従って処理する
  Then 両ファイルはアーカイブ先に移動される
  And pbi/ のバックログ一覧に反映される

Scenario: 未実装項目が残る PBI は pbi/ に残る
  Given 他の PBI に未チェック項目がある
  When 運用ルールに従って処理する
  Then それらは pbi/ に残る
```
