# PBI: APIキー解決の出所を診断出力に記録する

## ユーザーストーリー
開発者として、どのAPIキーがどの出所から解決されたか診断で確認したい、なぜなら無言フォールバックは誤スコープ混入やローテーション時の取り違えの原因になるから

## 優先度
- 順位: 07 / 13
- RICEスコア: 16（Reach=10 / Impact=2 / Confidence=80% / Effort=1）
- 根拠: 開発者向けだがキー取り違えは実害が大きい。工数小で診断性が上がる

## ビジネス価値
キー混入トラブルの切り分け時間を短縮する。DEFAULT への無言フォールバックをなくす

## BDD受け入れシナリオ

```gherkin
Scenario: 解決したキーの出所が診断に出る
  Given 複数のキー候補が存在する
  When プロバイダーがキーを解決する
  Then どの出所（設定キー名・デフォルト等）が使われたか診断に記録される
  And キー本体は記録されない

Scenario: デフォルトへの無言フォールバックがない
  Given 設定にキーがない
  When 解決を試みる
  Then 明示的な警告とともに従来の挙動またはエラーになる
```
