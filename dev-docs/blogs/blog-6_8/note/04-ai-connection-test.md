# 「接続テスト」が本物になった

Yasumaro の AI 設定画面には「接続テスト」ボタンがあります。設定が正しいかを確かめるボタンです。

これが v6.7 で、ちゃんとしたテストになりました。

## 前は何がダメだったか

以前のテストは、AI サービスに「つながるか」だけを見ていました。

なので、テストが緑になっても、いざ本番でページを要約すると中身が空、ということがありました。キーは通っているけれど要約には使えない、モデル名が微妙に間違っている、といったズレを見つけられなかったのです。

## いまはどうなったか

テストボタンを押すと、実際に AI へ短い文章を投げて、返ってきた内容をその場で表示します。

画面に出るもの:

- どこに送ったか
- 何を送ったか
- 何が返ってきたか
- エラーが出た場合はその内容
- モデル名、かかった時間

テストが通れば、本番でも要約が動きます。当たり前のことですが、そうなっていませんでした。

## 遅くても進捗が見える

AI を複数登録している場合、上から順にテストします。いまどれをテスト中で、何秒経ったかが表示されます。

内蔵 AI のように返事が遅いものでも、固まっているのか処理中なのかが分かります。

## 失敗したときに原因が分かる

うまくいかないとき、画面の表示から見当がつきます。

- 「401」なら API キーの問題
- 「404」ならモデル名の問題
- 「つながった、でも返事が空」なら、AI 側の設定（出力できる長さなど）の問題

これまでは「赤くなった」しか分からなかったので、原因を探すのが大変でした。
