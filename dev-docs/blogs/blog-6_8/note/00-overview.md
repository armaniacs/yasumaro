# Yasumaro を半年ぶりに触る人へ — v6.7 で増えた4つの便利

Yasumaro は、ブラウザで読んだページを AI が要約して、Obsidian とローカルに自動で残していく拡張機能です。

しばらく使っていなかった人向けに、v6.6 から v6.7 のあいだで「体験として変わったところ」を4つだけ紹介します。細かいバグ修正はたくさんありますが、ここでは日々の使い勝手に効くものに絞ります。

## APIキーがなくても AI 要約が動くようになった

これまで AI 要約には、OpenAI や Gemini などの API キー登録が要りました。

v6.7 からは、Chrome や Microsoft Edge に組み込まれた AI をそのまま使えます。設定でプロバイダーに「Built-in AI」を選ぶだけ。キーは要りません。要約はパソコンの中で完結するので、ページの中身がどこかに送られる心配もありません。

初回だけ AI モデルのダウンロード（数分）があります。そのあとはネットがなくても動きます。クラウドの AI より少し遅いものの、記録はうしろで進むので、待たされる感覚はあまりありません。

## 要約から「ゴミ」がもっと消えるようになった

AI に本文を渡す前に、広告や定型文などのノイズを取り除く処理が入っています。ここが強くなりました。

- **選ぶだけのプリセット** — 「最小」「バランス」「強め」から選べます。細かく調整したい人は個別設定もできます
- **サイトごとの調整** — 「このサイトだけ強めに掃除する」といった設定をサイト単位で持てます
- **Cookie の同意バナー** — 「Cookie を許可しますか」のバナー文が要約に混ざらなくなりました
- **消えすぎたら報告** — 本文まで消えてしまったとき、ワンクリックで報告できます。報告は手元に残るだけで、どこにも送られません

ダッシュボードで「詳細を表示」を開くと、何がどれだけ除去されたかが件数で見えます。

## 古い履歴を安心して片付けられるようになった

記録が溜まってくると、ローカルの容量が気になってきます。

`Dashboard → Archive` から、指定した日付より前の履歴をファイル（`.db`）に書き出せるようになりました。手順は2段階です。

1. 日付を選んで対象件数を確認し、アーカイブファイルを作ってダウンロードする（この時点では本体はそのまま）
2. ダウンロードできたのを確認してから、本体の古い履歴を削除する

書き出したファイルは、あとから本体に戻せます。取り込まずに開いて中を見たり、タイトルを直したりもできます。「消す前に必ずバックアップができている」のがこの機能の要点です。

## 「接続テスト」が実際に効くようになった

AI の設定画面にある「接続テスト」ボタン。以前は緑になっても、本番で要約が空っぽになることがありました。

いまは、実際に AI へ短い文章を投げて、返ってきた内容をその場で表示します。何を送って何が返ったか、モデル名やかかった時間まで画面で見えます。テストが通れば本番でも動く、という当たり前の状態になりました。

## 戻ってくる人へ

v6.6 系からそのまま最新版に上げて大丈夫です。設定は引き継がれます。

内蔵 AI を使いたい場合だけ、対応ブラウザでの準備（フラグの有効化とモデルのダウンロード）が必要です。詳しい手順はセットアップガイドにあります。

## インストール方法

### Chrome を使っている人へ

事情があって、Chrome ウェブストアでの公開は現在停止しています（将来的に再開する可能性はあります）。当面は GitHub からダウンロードしてインストールしてください。

1. [最新リリース](https://github.com/armaniacs/yasumaro/releases/latest) から `yasumaro-<version>-chrome.zip` をダウンロードして展開します
2. `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします
3. 「パッケージ化されていない拡張機能を読み込む」から、展開したフォルダを選びます

### Edge を使っている人へ

Edge なら [Edge アドオンストア](https://microsoftedge.microsoft.com/addons/detail/yasumaro-ai-browsing-lo/cajkdicmjjpmmohmiodmilmgkaeeonep) からそのままインストールできます。
