React 19 の新機能をまとめてみた

by @tech_writer2026-08-15いいね 256
ReactFrontendJavaScript

React 19 では Server Components の安定化、Actions、useFormStatus、useOptimistic などの新 Hook が導入されました。本記事では主要な変更点をサンプルコード付きで解説します。まずは全体像を把握し、次に各機能の詳細を見ていきましょう。

1. Server Components の安定化

React Server Components (RSC) はサーバー側でレンダリングされ、クライアントに送信される JavaScript バンドルを削減します。Next.js 15 でもデフォルトで有効化されており、データフェッチをコンポーネント内で直接行える点が大きな利点です。従来の useEffect によるフェッチと比較して、コードの見通しが良くなり、パフォーマンスも向上します。

// app/page.tsx
async function Page() {
  const data = await fetch('https://api.example.com/posts');
  return <div>{data.title}</div>
}

2. Actions と useFormStatus

フォーム送信をサーバーアクションとして扱えるようになりました。useFormStatus で送信中の状態を取得でき、ローディング表示が簡単に実装できます。従来の onSubmit ハンドラと比べて、プログレッシブエンハンスメントが容易です。

具体的な実装例として、フォームの pending 状態をボタンの disabled 属性に紐付けるパターンが推奨されています。これにより二重送信を防ぎつつ、ユーザーに適切なフィードバックを提供できます。

3. useOptimistic

楽観的更新を宣言的に記述できる Hook です。サーバーからのレスポンスを待たずに UI を更新し、失敗時にはロールバックします。チャットアプリやいいね機能など、即時性が求められる UI で威力を発揮します。
